# Контракт · Санкт-Петербург — лендинг

Продающий одностраничный сайт по службе по контракту через Санкт-Петербург.

На сайте два направления:
1. **Контракт СВО** — по специальности, по возможности в тыл с полными льготами; перевозим из региона в СПб, выплата растёт с ~800 000 ₽ до 4 500 000 ₽ (секции `specialty`, `money`).
2. **Ядерные силы** — работа по профессии 5/2 в тылу, закрывает срочную службу, полный соцпакет, выплата 3 800 000 ₽, зарплата от 80 000 ₽ по городу (секция `nuclear`).

## Как открыть

Просто открой `index.html` в браузере — сервер не нужен. Сайт статический, готов к публикации на GitHub Pages.

## Из чего состоит

- `index.html` — вся структура и тексты
- `styles.css` — оформление и адаптив (мобилка / планшет / десктоп)
- `script.js` — мобильное меню, появление блоков, FAQ-аккордеон

## Что легко поменять под себя

**Телефоны.** В файле `index.html` номера стоят в ссылках `href="tel:..."` (`117`, `+78127131319`, `122`)
и в тексте кнопок. Поиском по `tel:` найдёшь все места. Меняешь номер в `href` и подпись рядом.

**Суммы и выплаты.** Все цифры — обычный текст в `index.html`:
контракт СВО — блок «Деньги» (`id="money"`), карточка-сравнение в первом экране, блок «Профессии»;
ядерные силы — блок `id="nuclear"` (зарплаты по городам, выплата 3,8 млн, льготы).
Правишь прямо в тексте. Цифры подаются как справочные — дисклеймеры внизу страницы трогать не нужно.

**Тексты.** Любой заголовок и абзац правится прямо в `index.html`. Структуру менять не обязательно.

**Фото (если захочешь добавить).** Сейчас сайт обходится без фотографий — он выглядит цельно за счёт
оформления. Когда появятся свои реальные фото (команда, офис, пункт отбора, ребята на службе) — они
будут конвертить лучше любого стока. Чтобы вставить фото, добавь в нужное место:
`<img src="photo.jpg" alt="описание">` и положи файл рядом с `index.html`.
Хорошие места под фото: первый экран, блок «По специальности», блок «Как идём».

**Цвета.** В начале `styles.css` блок `:root` — там переменные: `--red` (акцент/кнопки),
`--navy` (тёмные секции), `--gold` и др. Меняешь значение — меняется по всему сайту.

## Видео

Подключены официальные ролики Минобороны России с Rutube (секция `id="videos"`).
Чтобы заменить — поменяй ссылку в `src` у нужного `<iframe>`.

## Локальный предпросмотр (необязательно)

```
python -m http.server 5577
```
Затем открой `http://localhost:5577` в браузере.
