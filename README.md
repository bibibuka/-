# Стальной рубеж

Статичный военно-тактический лендинг с местами под фото, видео и редактируемые текстовые блоки.

## Как открыть

Откройте `index.html` в браузере. Сервер не нужен.

## Медиа

- Кнопка `Сменить фон` меняет главное фото.
- Кнопки с иконкой загрузки в медиа-блоках подставляют локальные фото или видео.
- Загруженные через страницу файлы отображаются только в текущей сессии браузера. Для постоянной версии положите файлы в папку проекта и замените `src`/`poster` в `index.html`.

## Текст

Заголовки и абзацы на странице редактируются кликом. Изменения сохраняются в `localStorage` браузера. Кнопка `Сбросить` возвращает исходные тексты.
